## A gazdi kérései a képhez képest (döntésekbe átvezetve, `docs/decisions.md`)
1. A szőnyeg háromszögei nagyobbak legyenek, mint a képen.
2. Az ajtó animált: napközben nyitva, este vagy rossz időben csukva; csukott ajtónál az ablakon szűrődik be a holdfény.
3. A tányérok helyett képek a falon.
4. A sarokülő felett a falon egy óra.
5. A nézetváltás nem oldalra, hanem felfelé, az ajtón át: Lili ki- vagy beszalad. Az ajtóra koppintás is váltson, nem csak a gomb.
6. Először az aktuális, őszi évszak készül el; a többi évszak későbbi frissítésekben.
